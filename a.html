Pertanyaan Umum

Apakah nonton di Animekyu gratis?
Ya! Animekyu menyediakan streaming gratis dengan kualitas 480p. Untuk pengalaman tanpa iklan dan kualitas 1080p, kamu bisa upgrade ke Premium.
Apa bedanya Free dan Premium?
Free: 480p, ada iklan, 3 episode per anime. Premium: 1080p, tanpa iklan, unlimited episode, bonus 1.5x poin, skip intro/outro.
Kenapa video kadang gagal dimuat?
Bisa jadi karena koneksi internet atau server sedang sibuk. Coba refresh halaman atau ganti kualitas video. Jika masih error, laporkan melalui menu Laporkan Masalah.
Bagaimana cara upgrade Premium?
Klik menu Premium di sidebar, pilih paket Bulanan (Rp10.000) atau Tahunan (Rp50.000), lalu ikuti instruksi pembayaran.
Pencarian tidak menemukan anime yang saya cari
Pastikan ejaan judul sudah benar. Kamu juga bisa mencari berdasarkan genre di menu Genre List. Jika masih tidak ditemukan, laporkan melalui menu Laporkan Masalah.
Apakah Animekyu menyimpan file video sendiri?
Animekyu menampilkan konten dari sumber pihak ketiga dan tidak meng-host file video. Kami hanya menyediakan link streaming dari berbagai sumber.
Bagaimana cara reset password?
Fitur reset password akan segera hadir. Untuk sementara, hubungi support melalui email atau laporkan masalah.
